# Before-and-after photos

The homepage gallery loads real photos from this folder automatically. Until a photo is here, that slot shows a labeled placeholder.

You do not need to edit `index.html`. Save the file with the exact name below and redeploy.

## Where to drop each photo

Put files in `assets/before-after/`. Names are case-sensitive.

| Slot | Save the photo as |
| --- | --- |
| Bulk trash and junk removal, before | `bulk-trash-before.jpg` |
| Bulk trash and junk removal, after | `bulk-trash-after.jpg` |
| Apartment trash-outs, before | `apartment-trash-out-before.jpg` |
| Apartment trash-outs, after | `apartment-trash-out-after.jpg` |
| Property and dumpster-area cleanups, before | `dumpster-area-before.jpg` |
| Property and dumpster-area cleanups, after | `dumpster-area-after.jpg` |
| Breezeway cleaning, before | `breezeway-before.jpg` |
| Breezeway cleaning, after | `breezeway-after.jpg` |

`.jpeg`, `.webp`, and `.png` work too. If more than one format is present, `.jpg` is used first, then `.jpeg`, `.webp`, and `.png`.

## Photo tips

- Landscape photos look best. Aim for about 1600×1200 pixels or larger.
- Use photos of Waste Be Gone Now jobs that you have permission to publish.
- The matching `.svg` placeholder can stay in this folder. It only shows when the real photo is missing.
- Shoot the same spot for the before and the after so the pair is easy to compare.

The placeholder image itself is marked “Photo coming soon” and prints the filename to use.
