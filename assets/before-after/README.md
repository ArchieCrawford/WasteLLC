# Before-and-after photos

Real job photos are already filled in for bulk trash, dumpster-area cleanup, and breezeway cleaning.

The apartment trash-out pair is hidden on the homepage until both photos exist. Save them here with these exact names and redeploy. The page will show that pair on its own. Names are case-sensitive.

| Slot | Save the photo as |
| --- | --- |
| Apartment trash-outs, before | `apartment-trash-out-before.jpg` |
| Apartment trash-outs, after | `apartment-trash-out-after.jpg` |

`.jpeg`, `.webp`, and `.png` work too. If more than one format is present, `.jpg` is used first, then `.jpeg`, `.webp`, and `.png`.

To replace a photo that is already on the site, overwrite the matching file:

| Slot | File |
| --- | --- |
| Bulk trash and junk removal, before | `bulk-trash-before.jpg` |
| Bulk trash and junk removal, after | `bulk-trash-after.jpg` |
| Property and dumpster-area cleanups, before | `dumpster-area-before.jpg` |
| Property and dumpster-area cleanups, after | `dumpster-area-after.jpg` |
| Breezeway cleaning, before | `breezeway-before.jpg` |
| Breezeway cleaning, after | `breezeway-after.jpg` |

Landscape photos look best. About 1600 pixels wide is enough. The labeled `.svg` placeholders stay in this folder for the apartment slot only. They show only if that card is visible and the real photo is missing.

Originals and two collage panels that are not a matched pair are in `assets/photos/`. Those panels are a second stained stairwell floor and an overflowing dumpster. They are not shown as a before-and-after because they are different places.
